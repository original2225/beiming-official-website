# 北冥官网系统设计文档

版本：0.1

## 总体方向

北冥官网从零重新设计。当前仓库不继承旧代码，只保留新的文档、规则和后续实现。

系统采用前后端分离设计。前端负责官网展示和交互体验，后端按模块拆分服务或包边界。是否使用微服务，需要在每个阶段根据复杂度确认，不能为了形式强行拆分。

## 初始技术原则

接口响应格式保持统一。

认证与权限必须集中管理，业务模块不得各自实现登录逻辑。

每个业务模块只拥有自己的数据和职责，不直接读取其他模块数据库。

模块之间通过明确接口通信。跨模块调用必须有失败兜底策略。

## 建议模块边界

`auth` 负责身份和权限。

`profile` 负责成员公开档案。

`community` 负责社区内容。

`notification` 负责站内通知。

`content` 负责官网内容管理。

`admin` 负责后台聚合入口，不直接吞掉业务服务职责。

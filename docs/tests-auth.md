# 北冥官网 auth 测试文档

版本：0.1

## 文档定位

本文档根据 `docs/contracts-auth.md` 生成，是 `auth` 微服务的正式测试契约。`auth` 的自动化测试必须覆盖本文档全部用例。没有自动化测试覆盖的接口行为，不计入完成。

本文档继承 `docs/contracts-common.md` 的统一响应、统一错误、分页、认证头、请求编号、错误码、基础角色、运维能力点、审计字段和风险等级要求。实现前必须先创建自动化测试并确认测试因为接口未实现或行为不满足而失败，然后才能编码。

## 测试完成标准

所有用例必须可自动化执行。每个接口至少覆盖成功路径、字段校验、认证失败、权限不足、资源不存在、状态冲突、幂等或并发边界、状态流转、失败降级和审计要求。后台写操作必须校验审计记录。涉及会话、邀请码次数、密码、角色能力点和 Minecraft 绑定的状态变化，必须同时断言操作前状态、操作后状态和失败回滚。

测试通过的含义是接口行为符合 `docs/contracts-auth.md` 和 `docs/contracts-common.md`，不是只返回 HTTP 成功。统一响应结构、错误码、请求编号、分页字段、敏感字段隐藏、会话吊销、审计落库和限流不变更数据，都属于通过条件。

| 测试组 | 覆盖范围 |
| --- | --- |
| `AuthCommonContractTest` | 统一响应、错误结构、请求编号、认证头、分页、敏感字段隐藏。 |
| `RegisterApiTest` | 注册、邀请码使用、注册幂等、并发、限流、事务回滚。 |
| `LoginSessionApiTest` | 登录、退出、当前用户、会话校验、会话过期和吊销。 |
| `PasswordResetApiTest` | 密码重置申请、确认、令牌状态、旧会话失效。 |
| `MinecraftBindingApiTest` | 绑定、重复绑定、冲突绑定、解绑和审计。 |
| `AdminUserApiTest` | 用户列表、详情、用户状态修改、角色能力点修改。 |
| `InvitationAdminApiTest` | 邀请码列表、创建、禁用、使用记录和权限边界。 |
| `AuthAuditAndSecurityTest` | 审计字段、限流、敏感字段、跨接口状态一致性。 |

## 基础测试数据

测试环境必须能创建一个初始 `OWNER`，该用户不通过注册接口生成。基础用户包括 `ownerUser`、`adminUser`、`helperUser`、`normalUser`、`disabledUser`、`bannedUser`、`deletedUser` 和 `pendingProfileUser`。`ownerUser` 拥有 `OWNER` 角色和全部运维能力点。`adminUser` 拥有 `ADMIN`。`helperUser` 拥有 `HELPER`。`normalUser` 拥有 `USER`。

邀请码测试数据包括一个有效 `PLAYER` 邀请码、一个有效 `ADMIN` 邀请码、一个已禁用邀请码、一个已过期邀请码、一个已用完邀请码和一个只剩一次使用次数的邀请码。Minecraft 绑定测试数据包括一个已绑定账号、一个未绑定账号和一个已占用的 Minecraft ID 与 UUID。

所有测试之间必须隔离数据。每个测试应使用独立用户名、展示名、邀请码或清理后的事务上下文，不能依赖测试执行顺序。

## 全局契约用例

| 用例 ID | 场景 | 操作 | 期望 |
| --- | --- | --- | --- |
| AUTH-COM-001 | 成功响应格式 | 调用任一成功接口 | HTTP 状态符合契约，响应包含 `code: 0`、`message: success` 和 `data`。 |
| AUTH-COM-002 | 错误响应格式 | 触发字段校验失败 | 返回公共错误码 `40001`，包含 `errors[]` 和 `requestId`。 |
| AUTH-COM-003 | 请求编号透传 | 携带 `X-Request-Id` 调用接口 | 响应头和响应体中的请求编号与传入值一致。 |
| AUTH-COM-004 | 请求编号生成 | 不携带 `X-Request-Id` 调用接口 | 服务端生成请求编号，响应和审计记录可追踪同一编号。 |
| AUTH-COM-005 | Bearer 格式错误 | 使用非 Bearer 认证头访问登录后接口 | 返回 `41003`，不得执行业务逻辑。 |
| AUTH-COM-006 | 缺失认证 | 访问任一登录后接口 | 返回 `41000`。 |
| AUTH-COM-007 | 分页格式 | 调用用户列表、邀请码列表或使用记录列表 | `data` 包含 `items`、`page`、`pageSize`、`total`。 |
| AUTH-COM-008 | 分页参数错误 | `page=0` 或 `pageSize=101` | 返回 `40002`。 |
| AUTH-COM-009 | 敏感字段隐藏 | 调用用户详情、用户列表和邀请码列表 | 不返回密码哈希、完整邀请码原始码、重置令牌或会话令牌明文。 |
| AUTH-COM-010 | 审计字段完整 | 执行任一后台写操作 | 审计包含公共契约要求的字段，且 `requestId` 与请求一致。 |

## 注册接口用例

| 用例 ID | 场景 | 操作 | 期望 |
| --- | --- | --- | --- |
| AUTH-REG-001 | 玩家邀请码注册成功 | 使用有效 `PLAYER` 邀请码注册 | HTTP `201`，返回 `SessionPayload`，用户角色为 `USER`，状态为 `PENDING_PROFILE`，邀请码 `usedCount` 加一，写入使用记录和 `AUTH_REGISTER_SUCCESS`。 |
| AUTH-REG-002 | 管理员邀请码注册成功 | 使用有效 `ADMIN` 邀请码注册 | 返回会话，授予邀请码绑定角色，写入 `AUTH_ADMIN_INVITATION_USED`。 |
| AUTH-REG-003 | 缺失必填字段 | 缺少 `invitationCode`、`username`、`password` 或 `displayName` | 返回 `40001`，不创建用户，不消耗邀请码。 |
| AUTH-REG-004 | 用户名格式错误 | 使用非法用户名 | 返回 `40001`，不创建用户。 |
| AUTH-REG-005 | 弱密码 | 密码不足 10 位或缺少字母数字组合 | 返回 `40001`，不创建用户。 |
| AUTH-REG-006 | 展示名格式错误 | 展示名过短、过长或为空 | 返回 `40001`，不创建用户。 |
| AUTH-REG-007 | 用户名重复 | 使用已存在用户名注册 | 返回 `43110`，不消耗邀请码。 |
| AUTH-REG-008 | 展示名重复 | 使用已存在展示名注册 | 返回 `43111`，不消耗邀请码。 |
| AUTH-REG-009 | 邀请码不存在 | 使用不存在的邀请码 | 返回 `43101`，不创建用户。 |
| AUTH-REG-010 | 邀请码已禁用 | 使用 `DISABLED` 邀请码 | 返回 `43112`，不创建用户，不新增使用记录。 |
| AUTH-REG-011 | 邀请码已过期 | 使用 `EXPIRED` 邀请码 | 返回 `43113`，不创建用户。 |
| AUTH-REG-012 | 邀请码次数用完 | 使用 `EXHAUSTED` 邀请码 | 返回 `43114`，不创建用户。 |
| AUTH-REG-013 | 幂等重复提交 | 相同 `idempotencyKey` 和相同请求体重复注册 | 两次返回同一用户和会话结果，邀请码只消耗一次。 |
| AUTH-REG-014 | 幂等键冲突 | 相同 `idempotencyKey` 搭配不同请求体 | 返回 `43002`，不创建第二个用户。 |
| AUTH-REG-015 | 邀请码并发最后一次使用 | 并发提交两个注册请求抢同一个剩余次数为 1 的邀请码 | 只有一个成功，另一个返回 `43114`，最终 `usedCount` 只增加一次。 |
| AUTH-REG-016 | 注册限流 | 同一 IP 高频注册 | 返回 `44101`，不创建用户，不消耗邀请码。 |
| AUTH-REG-017 | 注册事务回滚 | 人为触发会话创建失败 | 用户、凭证、邀请码次数和使用记录全部回滚。 |
| AUTH-REG-018 | 禁止注册 OWNER | 使用绑定 `OWNER` 的异常邀请码注册 | 返回权限或状态冲突错误，不创建 `OWNER`。 |
| AUTH-REG-019 | 统一响应和请求编号 | 成功和失败注册各执行一次 | 响应结构符合公共契约，失败响应包含 `requestId`。 |

## 登录、退出和会话用例

| 用例 ID | 场景 | 操作 | 期望 |
| --- | --- | --- | --- |
| AUTH-LOGIN-001 | 登录成功 | 使用正确用户名和密码登录 | HTTP `200`，返回 `SessionPayload`，更新 `lastLoginAt`，写入 `AUTH_LOGIN_SUCCESS`。 |
| AUTH-LOGIN-002 | 用户名不存在 | 使用不存在用户名登录 | 返回 `41100`，响应不得暴露用户不存在。 |
| AUTH-LOGIN-003 | 密码错误 | 使用错误密码登录 | 返回 `41100`，响应与用户名不存在场景保持同类语义。 |
| AUTH-LOGIN-004 | 禁用用户不能登录 | `DISABLED` 用户登录 | 返回 `41101`，不创建会话。 |
| AUTH-LOGIN-005 | 封禁用户不能登录 | `BANNED` 用户登录 | 返回 `41102`，不创建会话。 |
| AUTH-LOGIN-006 | 软删除用户不能登录 | `DELETED` 用户登录 | 返回 `43116`，不创建会话。 |
| AUTH-LOGIN-007 | 登录限流 | 同一用户名或 IP 连续失败超过阈值 | 返回 `44100`，写入 `AUTH_LOGIN_RISK_BLOCKED`。 |
| AUTH-LOGIN-008 | 登录字段校验 | 缺少用户名或密码 | 返回 `40001`，不创建会话。 |
| AUTH-LOGIN-009 | 登录幂等重复 | 相同 `idempotencyKey` 和请求体重复登录 | 返回同一幂等结果或等价有效会话，不产生冲突。 |
| AUTH-LOGOUT-001 | 退出成功 | 使用有效令牌退出 | 返回 `data: null`，当前会话被吊销，写入 `AUTH_LOGOUT_SUCCESS`。 |
| AUTH-LOGOUT-002 | 重复退出幂等 | 对同一会话重复退出 | 第二次仍返回成功，不重复写审计。 |
| AUTH-LOGOUT-003 | 未登录退出 | 不带令牌退出 | 返回 `41000`。 |
| AUTH-LOGOUT-004 | 退出后访问当前用户 | 退出后用旧令牌访问 `/me` | 返回 `41103` 或公共会话无效错误。 |
| AUTH-ME-001 | 当前用户成功 | 有效会话访问 `/me` | 返回 `UserSummary`，包含角色、能力点、状态和 Minecraft 绑定摘要。 |
| AUTH-ME-002 | 当前用户未登录 | 不带令牌访问 `/me` | 返回 `41000`。 |
| AUTH-ME-003 | 当前用户会话过期 | 使用过期令牌访问 `/me` | 返回 `41002`。 |
| AUTH-ME-004 | 当前用户会话吊销 | 使用被吊销令牌访问 `/me` | 返回 `41103`。 |
| AUTH-ME-005 | 用户状态变化后会话失效 | 管理员禁用、封禁或删除用户后使用旧令牌访问 `/me` | 返回对应状态错误，不返回用户摘要。 |
| AUTH-VERIFY-001 | 会话校验成功 | 有效会话访问 `/session/verify` | 返回 `valid: true`、`expiresAt` 和用户摘要。 |
| AUTH-VERIFY-002 | 会话校验失败 | 无效、过期或吊销会话访问 `/session/verify` | 返回错误响应，不返回 `valid: false` 的成功响应。 |

| --- | --- | --- | --- |
| AUTH-PWD-001 | 申请密码重置成功 | 对存在用户提交重置申请 | 返回 `data: null`，生成一次性令牌，写入 `AUTH_PASSWORD_RESET_REQUESTED`。 |
| AUTH-PWD-002 | 不存在用户申请重置 | 对不存在用户名提交重置申请 | 返回与存在用户相同的成功响应，不生成令牌，不暴露账号存在性。 |

| AUTH-PWD-005 | 确认重置成功 | 使用有效令牌和合规新密码 | 返回成功，密码哈希更新，令牌标记已使用，用户全部旧会话失效，写入 `AUTH_PASSWORD_RESET_CONFIRMED`。 |
| AUTH-PWD-006 | 令牌不存在 | 使用不存在令牌确认 | 返回 `41104`。 |
| AUTH-PWD-007 | 令牌过期 | 使用过期令牌确认 | 返回 `41104`。 |
| AUTH-PWD-008 | 令牌重复使用 | 同一令牌确认两次 | 第一次成功，第二次返回 `41104`。 |
| AUTH-PWD-009 | 新密码弱 | 使用不符合规则的新密码 | 返回 `40001`，令牌仍未使用，密码不变。 |
| AUTH-PWD-010 | 新密码等于旧密码 | 使用当前密码作为新密码 | 返回 `43001`，令牌仍未使用或按实现保持可重试状态。 |
| AUTH-PWD-011 | 旧会话失效 | 重置成功后用重置前令牌访问 `/me` | 返回会话吊销或无效错误。 |
| AUTH-PWD-012 | 新密码可登录 | 重置成功后使用新密码登录 | 登录成功，旧密码登录失败。 |
| AUTH-PWD-013 | 确认失败审计 | 使用无效令牌确认 | 写入 `AUTH_PASSWORD_RESET_FAILED` 或安全日志。 |

| AUTH-INV-CREATE-002 | OWNER 创建管理员邀请码 | `OWNER` 创建 `ADMIN` 邀请码绑定 `ADMIN` 或 `HELPER` | 创建成功，风险等级为 `MEDIUM`。 |
| AUTH-INV-CREATE-003 | ADMIN 创建管理员邀请码 | `ADMIN` 创建 `ADMIN` 邀请码 | 返回 `42102`，不创建邀请码。 |
| AUTH-INV-CREATE-004 | 创建授予 OWNER 的邀请码 | 任意管理员创建绑定 `OWNER` 的邀请码 | 返回权限或字段错误，不创建邀请码。 |
| AUTH-INV-CREATE-005 | ADMIN 越权授予权限 | `ADMIN` 创建带 `ADMIN` 或运维能力点的玩家邀请码 | 返回 `42103` 或 `42102`，不创建邀请码。 |
| AUTH-INV-CREATE-006 | 字段校验 | 缺少 `type`、`boundRoles`、`maxUses` 或 `reason` | 返回 `40001`。 |
| AUTH-INV-CREATE-007 | 使用次数非法 | `maxUses` 小于 1 或大于 1000 | 返回 `40001`。 |
| AUTH-INV-CREATE-008 | 过期时间非法 | `expiresAt` 早于当前时间 | 返回 `40001`。 |
| AUTH-INV-CREATE-009 | 创建幂等重复 | 相同创建者、相同 `idempotencyKey` 和请求体重复创建 | 返回同一个邀请码和同一个 `rawCode`，只写一次审计。 |
| AUTH-INV-CREATE-010 | 创建幂等冲突 | 相同 `idempotencyKey` 搭配不同请求体 | 返回 `43002`。 |
| AUTH-INV-CREATE-011 | 原始码只在创建返回 | 创建后查询邀请码列表和详情类数据 | 不再返回完整 `rawCode`。 |
| AUTH-INV-DISABLE-001 | 禁用邀请码成功 | 创建者 `ADMIN` 禁用自己的 `PLAYER` 邀请码 | 状态变为 `DISABLED`，写入 `AUTH_INVITATION_DISABLED`。 |
| AUTH-INV-DISABLE-002 | OWNER 禁用任意邀请码 | `OWNER` 禁用 `PLAYER` 或 `ADMIN` 邀请码 | 禁用成功。 |
| AUTH-INV-DISABLE-003 | ADMIN 禁用他人邀请码 | `ADMIN` 禁用他人创建的邀请码 | 返回 `42001`，状态不变。 |
| AUTH-INV-DISABLE-004 | 禁用不存在邀请码 | 禁用不存在 ID | 返回 `43101`。 |
| AUTH-INV-DISABLE-005 | 重复禁用幂等 | 对已禁用邀请码再次禁用 | 返回成功，不重复写审计。 |
| AUTH-INV-DISABLE-006 | 缺少禁用原因 | 不传 `reason` | 返回 `40001`，状态不变。 |
| AUTH-INV-USAGE-001 | 使用记录列表成功 | 有权限管理员查询邀请码使用记录 | 返回分页记录，包含使用用户、时间、来源 IP 和请求编号。 |
| AUTH-INV-USAGE-002 | 使用记录权限不足 | `ADMIN` 查询无权查看的邀请码记录 | 返回 `42001`。 |
| AUTH-INV-USAGE-003 | 邀请码不存在 | 查询不存在邀请码使用记录 | 返回 `43101`。 |
| AUTH-INV-USAGE-004 | 分页参数错误 | 使用非法分页参数 | 返回 `40002`。 |

## 状态流转和跨接口用例

| 用例 ID | 场景 | 操作 | 期望 |
| --- | --- | --- | --- |
| AUTH-STATE-001 | 用户注册初始状态 | 完成注册 | 用户状态为 `PENDING_PROFILE`。 |
| AUTH-STATE-002 | 用户恢复 | 将 `DISABLED` 用户恢复为 `ACTIVE` | 状态变更成功，审计记录前后状态。 |
| AUTH-STATE-003 | BANNED 恢复 | 将 `BANNED` 用户恢复为 `ACTIVE` | 状态变更成功，旧会话仍保持失效。 |
| AUTH-STATE-004 | DELETED 不可恢复 | 尝试恢复 `DELETED` 用户 | 返回 `43116`。 |
| AUTH-STATE-005 | 邀请码禁用优先 | 禁用一个同时过期或用完的邀请码 | 状态展示为 `DISABLED`。 |
| AUTH-STATE-006 | 过期邀请码状态 | 当前时间超过 `expiresAt` | 状态展示为 `EXPIRED`，注册返回 `43113`。 |
| AUTH-STATE-007 | 用完邀请码状态 | `usedCount >= maxUses` | 状态展示为 `EXHAUSTED`，注册返回 `43114`。 |
| AUTH-STATE-008 | 角色降权会话处理 | 管理员被移除 `ADMIN` 后访问用户列表 | 旧会话不能继续访问后台。 |
| AUTH-STATE-009 | 用户禁用会话处理 | 用户被禁用后访问任一登录后接口 | 返回状态错误或会话无效。 |

## 限流和安全用例

| 用例 ID | 场景 | 操作 | 期望 |
| --- | --- | --- | --- |
| AUTH-SEC-001 | 注册限流不改变数据 | 触发注册限流后检查邀请码 | 邀请码次数、使用记录和用户数量不变。 |
| AUTH-SEC-002 | 登录失败不暴露账号 | 对不存在用户和错误密码分别登录 | 错误码和消息语义一致。 |
| AUTH-SEC-003 | 密码不明文保存 | 注册或重置密码后检查持久化凭证 | 不存在明文密码，哈希算法字段或格式可识别。 |
| AUTH-SEC-004 | 邀请码不明文保存 | 创建邀请码后检查持久化数据 | 不长期保存完整原始码，只保存哈希或不可逆校验信息。 |
| AUTH-SEC-005 | 后台写操作审计失败 | 模拟审计写入失败后执行后台写操作 | 接口失败，业务数据回滚。 |
| AUTH-SEC-006 | 普通注册审计失败 | 模拟注册审计失败 | 注册主流程可成功，但必须有安全日志或补偿记录。 |
| AUTH-SEC-007 | 请求编号可追踪 | 执行注册、登录、后台修改各一次 | 业务数据、审计记录和响应中的请求编号一致。 |

## 实现前失败验证

自动化测试创建完成后，必须先运行 auth 全部测试。由于接口尚未实现或行为尚未满足，测试必须失败。失败原因应指向缺失接口、缺失路由、缺失字段、错误码不匹配、审计未落库或状态未变化，不能是测试语法错误、环境缺失或断言写错。

如果测试在实现前通过，说明测试没有覆盖真实接口行为，必须修正测试后重新确认失败。只有完成这一步，才允许进入 `auth` 生产代码实现。

## 最终验收

`docs/contracts-auth.md` 中列出的全部接口都必须有对应自动化测试。本文档全部用例必须通过。任何失败测试都不能跳过，不能降低 API 契约、测试口径或系统设计来换取通过。

验收时至少运行 auth 全部自动化测试，并确认统一响应、错误码、分页、认证、权限、邀请码并发、密码重置、Minecraft 绑定、用户状态流转、角色能力点、限流和审计全部通过。`auth` 通过后，后续服务才能稳定适配它的用户摘要、角色、能力点、Minecraft 绑定状态和认证上下文。

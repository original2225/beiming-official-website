# 北冥官网需求文档

版本：0.1

## 项目定位

北冥官网是北冥项目的正式线上门户。它应承担品牌展示、成员展示、社区内容、公告资讯、活动信息和后续管理入口的统一承载。

## 当前阶段目标

第一阶段先完成信息架构和技术架构，不急着写业务代码。新仓库必须先把需求、系统设计和开发规则定清楚，再逐步实现模块。

## 核心用户

游客可以浏览官网公开内容、成员介绍、公告、社区公开内容和项目介绍。

注册成员可以登录、维护个人资料、参与社区互动、接收站内通知。

管理员可以管理内容、成员资料、公告、社区审核和运营配置。

## 初始模块

账号与权限模块负责注册、登录、会话、角色和用户状态。

成员档案模块负责成员公开资料、Minecraft 身份、头像、成员组和成员状态。

社区模块负责板块、帖子、评论、点赞、收藏、举报、投票和审核。

通知模块负责站内通知、未读数、已读状态和通知归档。

内容模块负责官网公告、文章、页面内容和素材管理。

## 开发约束

一次只开发一个模块。每个模块必须有明确边界、接口说明、测试和验收标准。

未经确认，不允许修改已经完成并上传的模块。

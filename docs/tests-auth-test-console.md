# 北冥官网 auth 测试台测试文档

版本：0.1

## 文档定位

本文档是 `frontend/auth-test-console` 的正式测试文档。该前端只作为 auth 微服务本地联调工具，不承担正式业务前端职责。测试台必须以 `docs/contracts-auth.md` 和 `docs/tests-auth.md` 为接口行为来源，只调用 auth 已有 API，不新增业务规则。

## 测试目标

测试台必须能让开发者在浏览器里完成 auth 核心接口联调。页面中的导航、表单、按钮、响应面板和错误状态都必须有可验证行为，不能只展示静态样式。所有测试用例通过后，才允许认为测试台可用于 auth 本地测试。

## 启动约束

测试台默认通过 Vite 在 `127.0.0.1` 启动，允许端口为 `5173`、`5174` 或 `5182`。auth 后端固定为 `http://localhost:8101`。当后端未启动时，页面必须能正常渲染并显示离线或请求失败状态，不能整页崩溃。浏览器测试应优先复用本机 Microsoft Edge，不要求下载浏览器。

## 用例总览

| 用例 ID | 场景 | 操作 | 期望 |
| --- | --- | --- | --- |
| AUTH-UI-001 | 页面首屏渲染 | 打开测试台 | 显示品牌、顶部导航、节点选择、状态卡、接口操作、邀请码管理和最近事件。 |
| AUTH-UI-002 | 顶部概览按钮 | 点击 `概览` | 页面滚动到概览区，`概览` 显示为当前选中项。 |
| AUTH-UI-003 | 顶部账号按钮 | 点击 `账号` | 页面滚动到账号接口操作区，`账号` 显示为当前选中项。 |
| AUTH-UI-004 | 顶部会话按钮 | 点击 `会话` | 页面滚动到会话状态卡区，`会话` 显示为当前选中项。 |
| AUTH-UI-005 | 顶部邀请码按钮 | 点击 `邀请码` | 页面滚动到邀请码管理区，`邀请码` 显示为当前选中项。 |
| AUTH-UI-006 | 顶部日志按钮 | 点击 `日志` | 页面滚动到最近事件区，`日志` 显示为当前选中项。 |
| AUTH-UI-007 | 顶部导航不可重叠 | 在 1440px 和 1988px 宽度打开页面 | 顶部按钮文字保持横排，不与搜索框、节点框或用户卡重叠。 |
| AUTH-UI-008 | 后端未启动降级 | 后端不可用时打开页面 | 状态显示 `OFFLINE` 或响应码 `-1`，页面仍可操作导航和填写表单。 |
| AUTH-UI-009 | 快速登录 | 后端启动后点击 `快速登录` | 使用本地种子账号登录，状态卡显示 `READY`，当前用户显示 `owner`。 |
| AUTH-UI-010 | 当前用户 | 登录后点击 `当前用户` | 最近事件显示当前用户成功响应，用户摘要不为空。 |
| AUTH-UI-011 | 会话校验 | 登录后点击 `会话校验` | 最近事件显示 `valid: true`。 |
| AUTH-UI-012 | 用户列表 | OWNER 或 ADMIN 登录后点击 `用户列表` | 最近事件显示分页 `items`，包含种子用户。 |
| AUTH-UI-013 | 邀请码列表 | OWNER 或 ADMIN 登录后点击 `邀请码` 快捷按钮或刷新按钮 | 邀请码列表显示 `PLAYER`、`ADMIN` 或创建的邀请码摘要，不展示完整历史 rawCode。 |
| AUTH-UI-014 | 创建邀请码 | OWNER 登录后提交邀请码表单 | 最近邀请码区显示本次返回的完整 `rawCode`，列表新增对应摘要。 |
| AUTH-UI-015 | 禁用邀请码 | 点击邀请码列表中的禁用按钮 | 对应邀请码状态变为 `DISABLED`，最近事件显示成功响应。 |
| AUTH-UI-016 | 注册表单 | 使用可用玩家邀请码提交注册 | 返回会话，当前用户切换为新注册用户。 |
| AUTH-UI-017 | Minecraft 绑定 | 登录后提交合法 Minecraft ID、UUID 和验证码 | 最近事件显示绑定对象；重复绑定同一身份保持成功。 |
| AUTH-UI-018 | 退出登录 | 登录后点击 `退出` | token 清空，当前用户回到未登录状态，受保护按钮不可继续提交。 |
| AUTH-UI-019 | 错误响应展示 | 输入错误密码或无权限操作 | 最近事件展示统一错误响应，不吞掉错误码和 message。 |
| AUTH-UI-020 | 构建验证 | 执行前端构建 | TypeScript 和 Vite 构建成功，无类型错误。 |
| AUTH-UI-021 | 后端契约回归 | 执行 auth 后端测试 | `docs/tests-auth.md` 对应自动化测试全部通过。 |

## 验收口径

`AUTH-UI-001` 到 `AUTH-UI-021` 必须都有自动化或可复现验证。顶部导航按钮必须是真实交互，点击后要改变当前选中状态并移动到对应区域。所有接口按钮必须在后端可用时调用真实 auth API，在后端不可用时显示明确失败响应。测试通过不能依赖手工刷新、浏览器缓存或隐藏的旧 token。
